# pi-plusvibe-provider

Провайдер [PlusVibeAPI](https://plusvibeapi.ru/docs) (шлюз `plusvibeapi.ru`) для [Pi](https://github.com/earendil-works/pi).
PlusVibeAPI — OpenAI-совместимый роутер, поэтому расширение не реализует свой протокол:
оно передаёт работу встроенной реализации Pi `openai-completions` и добавляет только
адрес, авторизацию и каталог моделей.

> English version of this document: [README.md](./README.md).

> **Неофициальное расширение.** Проект не связан с оператором PlusVibeAPI. Каждый
> пользователь подключает свой ключ. Встроенный прокси с общим ключом или перепродажа
> доступа запрещены публичной офертой оператора.

## Статус и условия сервиса

Это неофициальное независимое клиентское расширение для PlusVibeAPI. Проект не связан с
оператором PlusVibeAPI, не одобрен и не поддерживается им. Названия «PlusVibeAPI» и «PlusVibe»
используются только чтобы обозначить сервис, с которым работает расширение. Права на эти
названия принадлежат их владельцам.

Каждый пользователь получает и использует собственный ключ API. Пакет не содержит общего ключа,
не работает как прокси и не даёт доступ через аккаунт автора.

Использование PlusVibeAPI регулируется [публичной офертой](https://plusvibeapi.ru/legal/terms)
оператора. Лицензия MIT относится к коду этого проекта; она не даёт прав на сервис, на материалы
оператора и на результаты генерации сторонних моделей.

Оферта оператора запрещает передавать и перепродавать доступ по его ключам без отдельного
письменного соглашения. Не обходите средства контроля доступа и лимиты сервиса.

## Что даёт

- 60 моделей (Anthropic, OpenAI, Google, DeepSeek, Qwen, GLM, Grok, MiniMax, Moonshot и др.)
  с корректными `contextWindow`, `maxTokens`, поддержкой изображений и рассуждений.
- Автоподстановка уровня рассуждений (`thinkingLevelMap`) для моделей, у которых каталог
  публикует явные уровни (`low`/`medium`/`high`/…). Прочие модели используют умолчания Pi.
- `/login` — мастер ввода ключа с проверкой через `GET /v1/models`.
- `/plusvibe-balance` — остаток на счёте (`GET /v1/balance`) и текущий курс рубля.
- Курс рубля подтягивается автоматически (ежедневный курс ЦБ РФ) и пересчитывает цены моделей в доллары для Pi.
- Обновление каталога во время работы из публичных конечных точек провайдера;
  при недоступности сети используется снимок, встроенный в расширение.

## Установка

1. Скопируйте репозиторий и установите зависимости (нужны только для разработки; само
   расширение запускается из исходников через Pi):

   ```bash
   git clone <repo> ~/sandbox/pi-plusvibe-provider
   cd ~/sandbox/pi-plusvibe-provider && npm install
   ```

2. Добавьте путь в `~/.pi/agent/settings.json` в список `packages`:

   ```json
   {
     "packages": ["~/sandbox/pi-plusvibe-provider"]
   }
   ```

   Абсолютный путь и путь относительно `~/.pi/agent` работают одинаково.

3. Перезапустите Pi и выберите модель командой `/model` → `plusvibe`.

## Ключ API

Ключи начинаются с `sk-pv-` и создаются в личном кабинете https://plusvibeapi.ru/.
Используйте любой из способов:

| Способ | Как | Когда подходит |
| --- | --- | --- |
| Переменная окружения | `export PLUSVIBE_API_KEY='sk-pv-…'` в `~/.bashrc`, затем перезапуск Pi | Постоянная работа |
| Файл с ключом | `printf '%s' 'sk-pv-…' > ~/.config/plusvibe/key && chmod 600 ~/.config/plusvibe/key` | Ключ не попадает в окружение, не нужен `models.json` |
| `/login` | `/login` → `PlusVibeAPI` → вставить ключ | Разовое подключение; ключ сохраняется в `auth.json` |
| Флаг CLI | `pi --provider plusvibe --model anthropic/claude-opus-5 --api-key sk-pv-…` | Разовый запуск |

Файл с ключом читает само расширение (по умолчанию `~/.config/plusvibe/key`; другой путь задаёт
`PLUSVIBE_API_KEY_FILE`). Права `600` обязательны.

Порядок приоритетов: `--api-key` → ключ из `auth.json` (после `/login`) → `PLUSVIBE_API_KEY` → файл с ключом.
Внимание: если ключ уже сохранён через `/login`, он перекрывает и переменную окружения, и файл.
Чтобы сменить ключ, выполните `/logout` (или передайте `--api-key` на один запуск).

## Команды

- `/model` — выбор модели (60 штук).
- `/thinking` — уровень рассуждений. Для моделей с явными уровнями недоступные значения
  скрыты; Pi сам приводит запрошенный уровень к ближайшему поддерживаемому.
- `/plusvibe-balance` — остаток на счёте.
- `/login` — привязать ключ.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `PLUSVIBE_API_KEY` | Ключ API (`sk-pv-…`). |
| `PLUSVIBE_API_KEY_FILE` | Путь к файлу с ключом. По умолчанию `~/.config/plusvibe/key`. |
| `PLUSVIBE_BASE_URL` | Другой адрес шлюза, по умолчанию `https://plusvibeapi.ru/v1`. Зеркало: `https://gw.plusvibeapi.ru/v1`. |
| `PLUSVIBE_RUB_PER_USD` | Курс вручную. Не задан — курс берётся из сети (см. ниже). `0` или `off` — расходы в интерфейсе отключены. |
| `PLUSVIBE_CACHE_DIR` | Каталог файла с курсом. По умолчанию `$XDG_CACHE_HOME/pi-plusvibe-provider` или `~/.cache/pi-plusvibe-provider`. |

### Про стоимость

Каталог провайдера публикует цены **только в рублях** за миллион токенов, а Pi показывает расходы в долларах.
Поэтому расширение раз в 12 часов берёт официальный курс рубля и пересчитывает цены.

Курс читается по порядку из источников (все без ключа):

1. `https://www.cbr-xml-daily.ru/daily_json.js` — зеркало данных ЦБ РФ в JSON;
2. `https://www.cbr.ru/scripts/XML_daily.asp` — исходная лента ЦБ РФ в XML;
3. `https://open.er-api.com/v6/latest/USD` — резервный источник, если ЦБ недоступен.

Курс сохраняется в файл (`~/.cache/pi-plusvibe-provider/usd-rate.json`). Если сеть недоступна, берётся
сохранённый курс — но не старше 7 суток: устаревший курс не используется, расходы показаны как `$0`,
пока не пройдёт удачный запрос. Файл пишется через временный файл и `rename`, поэтому параллельные
запуски Pi его не портят.

Порядок приоритетов: значение `PLUSVIBE_RUB_PER_USD` → сохранённый курс → `0` (расходы скрыты).
Курс ЦБ дневной, поэтому оценка в интерфейсе Pi приблизительная. Точные суммы — в личном кабинете
или командой `/plusvibe-balance`.

Если курс не нужен, задайте `PLUSVIBE_RUB_PER_USD=0`. Если нужен свой курс, задайте число,
например `export PLUSVIBE_RUB_PER_USD=85`.

Источники курса требуют указания ссылки: [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/),
[Банк России](https://www.cbr.ru/development/SXML/), [exchangerate-api.com](https://www.exchangerate-api.com/docs/free).

### Про уровень рассуждений

Pi передаёт уровень рассуждений в поле `reasoning_effort`. На этом роутере модели DeepSeek ведут себя не как
обычно: значения `none`, `minimal` и `low` **выключают** размышления, а `medium`, `high`, `xhigh` и `max`
включают. Родное поле DeepSeek `thinking: {type: …}` роутер игнорирует.

Так как уровень Pi по умолчанию — `low`, модель DeepSeek молча отвечала без блока размышлений.
Поэтому расширение для моделей DeepSeek:

- отправляет рассуждения в формате `reasoning: {effort: …}` (`compat.thinkingFormat = "openrouter"`);
- заменяет `minimal` и `low` на `medium`;
- для уровня `off` отправляет `effort: none`, то есть действительно выключает размышления.

Итог: любой уровень кроме `off` даёт блок размышлений, `off` — отключает его.
Модели других производителей работают как раньше (например, у `openai/gpt-5.6-luna` уровень `low`
даёт меньше размышлений, а не ноль).

## Разработка

```bash
npm install          # зависимости для разработки
npm run typecheck    # tsc --noEmit
npm test             # typecheck + все тесты
npm run sync:catalog # обновить src/catalog-snapshot.ts из сети
```

Структура:

| Файл | Что делает |
| --- | --- |
| `index.ts` | Регистрация провайдера, команда `/plusvibe-balance`, обновление каталога. |
| `src/catalog.ts` | Чистая логика: слияние каталогов, уровни рассуждений, конвертация цен. Без ввода-вывода. |
| `src/api.ts` | HTTP-запросы (модели, каталог, баланс) с таймаутами. |
| `src/api-key.ts` | Разбор и нормализация ключа, маскирование секретов в чужих сообщениях об ошибках. |
| `src/models.ts` | Преобразование записей каталога в определения моделей Pi. |
| `src/rate.ts` | Автоматический курс рубля: источники ЦБ, кеш, приоритеты. |
| `src/balance.ts` | Форматирование ответа `/v1/balance`. |
| `src/oauth.ts` | Поток `/login` (ввод и проверка ключа). |
| `src/catalog-snapshot.ts` | Сгенерированный снимок каталога. Правки вручную не нужны. |
| `scripts/sync-catalog.ts` | Генератор снимка. |
| `tests/` | Тесты на `node:assert` + `tsx`, без сети. |

После изменения `src/` выполните `npm test`. Сетевые тесты не требуются: HTTP подменяется
фиктивными `fetch`.

Проверка на изолированной конфигурации Pi (не трогает ваши настройки):

```bash
mkdir -p /tmp/pv-agent
echo '{"packages":["'"$PWD"'"]}' > /tmp/pv-agent/settings.json
PI_CODING_AGENT_DIR=/tmp/pv-agent PLUSVIBE_API_KEY=dummy pi --list-models plusvibe
```

## Ограничения

- Открыты только чат-модели. Эмбеддинги, изображения, видео, поиск и ASR не подключены.
- Цены в долларах приблизительные: провайдер публикует рубли, пересчёт идёт по дневному курсу ЦБ (см. выше).
- Модель, добавленная оператором после релиза, появится только после обновления снимка
  (`npm run sync:catalog`) — либо сразу в текущей сессии, если доступно сетевое обновление.

## Данные и приватность

Запросы уходят с вашей машины на заданный адрес шлюза. При работе через PlusVibeAPI оператор
передаёт содержимое запросов поставщикам моделей за пределами РФ, в том числе в США, Китай и ЕС,
как описано в его оферте.

Содержимое запроса может включать промпты, историю диалога, исходный код, содержимое файлов,
изображения и результаты инструментов, которые передаёт Pi. Проверяйте содержимое перед
отправкой.

Оферта оператора запрещает отправлять персональные данные. Не отправляйте персональные данные —
свои и третьих лиц. Расширение не находит и не обезличивает персональные данные автоматически.
Одного согласия недостаточно, чтобы отменить запрет оператора.

Не отправляйте учётные данные, конфиденциальную информацию и другие материалы, если вы не
вправе раскрывать их шлюзу и соответствующим поставщикам моделей. Пользователи и организации
обязаны сами оценить свои обязанности по защите данных, локализации и трансграничной передаче
(в частности, ст. 12 и ч. 5 ст. 18 Федерального закона № 152-ФЗ).

Расширение не поднимает сервер и не собирает телеметрию для автора. Оно делает сетевые запросы
за метаданными моделей и, если это не отключено, за курсом валют. Эти сервисы могут получать
обычные метаданные соединения, например ваш IP-адрес. Это утверждение относится только к
расширению, а не ко всем сетевым запросам процесса Pi.

Ключ API отправляется на заданный адрес шлюза. Задавайте `PLUSVIBE_BASE_URL` только для адреса,
которому доверяете: другой адрес получит и ключ, и содержимое запросов. Не публикуйте ключи API
и неотредактированные логи в открытых обращениях.
