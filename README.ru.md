Подключите [Pi](https://github.com/earendil-works/pi) к [PlusVibeAPI](https://plusvibeapi.ru/docs) — OpenAI-совместимому шлюзу для моделей Anthropic, OpenAI, Google, DeepSeek, Qwen и других разработчиков.

- **Выбирайте модели в Pi.** Размер контекста, поддержка изображений и рассуждений берутся из каталога провайдера.
- **Получайте обновления каталога.** Если сервисы каталога недоступны, расширение использует встроенный снимок.
- **Настраивайте рассуждения.** Расширение сопоставляет уровни с возможностями модели и учитывает особенности DeepSeek.
- **Проверяйте баланс.** Команда `/plusvibe-balance` показывает остаток на счёте. Автоматический пересчёт RUB → USD позволяет оценивать расходы в Pi.

## Быстрый старт

Нужны [Pi](https://github.com/earendil-works/pi#getting-started), Git и собственный API-ключ из [личного кабинета PlusVibeAPI](https://plusvibeapi.ru/). Ключ начинается с `sk-pv-`.

> [!IMPORTANT]
> Это неофициальное расширение. Проект не связан с PlusVibeAPI и не поддерживается оператором. Запросы передаются шлюзу и поставщикам моделей. Оферта оператора запрещает отправку персональных данных. Перед использованием прочитайте [об условиях и передаче данных](docs/privacy-and-terms.ru.md).

### 1. Установите расширение

```bash
pi install git:github.com/sandexzx/pi-plusvibe-provider
```

### 2. Подключите ключ

Запустите или перезапустите Pi, затем выполните:

```text
/login
```

Выберите **PlusVibeAPI** и вставьте ключ. Расширение проверит его, а Pi сохранит в `auth.json` для следующих сессий.

### 3. Выберите модель

Выполните `/model`, найдите `plusvibe` и выберите модель. Теперь можно отправить первый запрос.

Предпочитаете переменную окружения или файл с ключом? См. [настройку](docs/configuration.ru.md).

## Команды

| Команда | Что делает |
| --- | --- |
| `/model` | Выбор модели. Для поиска введите `plusvibe`. |
| `/thinking` | Настройка уровня рассуждений, если модель их поддерживает. |
| `/plusvibe-gateway` | Переключение между основным шлюзом и зеркалом. |
| `/plusvibe-balance` | Баланс PlusVibeAPI и используемый курс валют, если он доступен. |
| `/login` | Ввод и проверка API-ключа. |
| `/logout` | Удаление ключа, сохранённого через `/login`. |

## Что важно знать

- **Нет соединения, например из-за рубежа?** Используйте `/plusvibe-gateway` — она переключает на зеркало и обратно. Ручная настройка описана в [разделе о шлюзах](docs/configuration.ru.md#шлюз-и-зеркало).

- **Только чат-модели.** Поддерживаемым моделям можно передавать изображения. Генерация изображений, эмбеддинги, видео, поиск и распознавание речи не подключены.
- **Стоимость приблизительная.** PlusVibeAPI публикует цены в рублях, Pi показывает доллары. Пересчёт использует автоматически загружаемый курс. `$0` может означать отсутствие курса, а не бесплатные запросы. Точные списания смотрите в личном кабинете.
- **Резервный каталог не означает работу моделей без сети.** Для запросов нужны соединение со шлюзом и действующий ключ.
- **Вы используете свой ключ.** В расширении нет общего аккаунта, встроенного прокси и телеметрии для автора. Подробнее: [какие данные передаются и куда](docs/privacy-and-terms.ru.md).
